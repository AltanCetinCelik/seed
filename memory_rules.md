# Seed Memory Rules

Every Seed memory should have:
- type
- content
- importance

Allowed memory types:
- technical_progress
- mistake
- reflection
- seed_boundary
- job_goal
- seed_identity
- personal_rule

Rules:
- Save important project milestones.
- Save important mistakes and lessons.
- Save Seed identity changes carefully.
- Do not save random junk.
- Do not pretend stored memories are facts unless they are actually stored.
- If memory file is broken, start safely instead of crashing.
